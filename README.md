# 🧮 Java Calculator

A simple **Java Console-Based Calculator** built using Java. This project performs basic mathematical operations through a menu-driven interface using `switch` statements.

## 🚀 Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🟰 Remainder (Modulus)
- 🔢 Power Calculation
- 📌 Factorial Calculation
- 🔁 Menu-driven program using `do-while` loop
- ⌨️ User input with `Scanner`

## 🛠️ Technologies Used

- Java
- VS Code / IntelliJ IDEA
- Scanner Class
- Switch Statement
- Loops
- Methods
- Basic Arithmetic Operations

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/bitanughara/CALCULATOR.git
```

2. Navigate to the project folder:

```bash
cd CALCULATOR
```

3. Compile the program:

```bash
javac Calculator.java
```

4. Run the program:

```bash
java Calculator
```
